# BassClass: working notes for Claude

## Git workflow (always)

- Repository: https://github.com/josich/BassClass (remote `origin`, branch `main`).
- **Push every change.** After finishing any change (code, content, docs, assets): verify it, then commit and push to `origin main` in the same turn. Never leave work uncommitted or unpushed.
- The commit identity is already set locally in this repo (`josich` / `76693732+josich@users.noreply.github.com`). Don't change it or set a global one.
- End every commit message with the `Co-Authored-By` trailer from the session's attribution instructions.
- Windows PowerShell: write multi-line commit messages to a temp file and use `git commit -F <file>`. Here-strings are not passed to stdin.
- Order: `git add -A` → `git commit` → `git pull --rebase origin main` → `git push origin main`. The pull must come after the commit (rebase refuses unstaged changes). CI can push commits too: it committed the signing key `android/app/bassclass.p12` on its first run.
- Each push to `main` runs two GitHub Actions workflows:
  - **Build Android APK:** builds a signed release APK and publishes GitHub Release `v1.0.<run number>`. The user installs from https://github.com/josich/BassClass/releases/latest/download/BassClass.apk. Never delete or replace `bassclass.p12`: updates would stop installing over the old version.
  - **Publish web app (GitHub Pages):** deploys `web/` to https://josich.github.io/BassClass/, only once Pages → Source is "GitHub Actions"; until then it skips.
- Commits that change nothing in the app (QA reports, notes) end their first line with `[skip ci]` so no identical APK release is published.
- After pushing, check the runs at `https://api.github.com/repos/josich/BassClass/actions/runs` and fix any failure before reporting the work as done.

## Before committing

1. Start the dev server: `python tools/serve.py`, or the `bassclass` launch config. It serves `web/` on http://localhost:8765.
2. In the page console run `(await import('/js/selftest.js')).run()`. It must report `problems: 0`. It builds every exercise on 4/5/6-string basses and checks every note.
3. If exercises were added or changed, regenerate the catalogue: `(await import('/js/selftest.js')).saveCatalogue()` → `docs/CATALOGUE.md`.
4. Check UI changes visually in the browser pane at a landscape phone size (e.g. 800×380).

## Project facts

- `web/` is the whole app: static ES modules, no build step. `android/` wraps it in a WebView (`assets.srcDirs("../../web")`).
- This PC has no JDK, Android SDK, Node, Gradle or numpy, so APKs are built only by GitHub Actions. Audio processing runs in the browser (`web/js/dev/sampleprep.js`).
- Exercises live in `web/js/curriculum/`, one file per module, with shared helpers in `common.js`. See README "Adding an exercise".
- The guided Course (user, 2026-10-20) lives in `web/js/course/`: `data.js` (stages → units → lessons → steps; a step = exercise id + preset options `p` + `from`/`goal` tempo), `progress.js` (localStorage `bassclass.course.v1`), and `web/js/ui/course.js` (Home block, `#/course`, `#/course/<lesson>`, `#/course/placement`). An exercise opened from a lesson carries `ls=<lesson>.<step>` (and `demo=1` for "Hear it", `rv=1` for a review). Lesson ids are stored: never rename one. Steps are stored by index: append new steps, never insert or reorder. A step on an exercise with a subdivision selector carries `sub` (the self-test checks it). The self-test checks every step. See README "Adding a course lesson".
- Exercise numbers follow the Library order: level, then topic (PATH_ORDER), then the order of the module's `export default [...]` list (computed in `curriculum/index.js`). Put a new exercise where it belongs in that list; the ones after it move up by one (user's choice, 2026-10-15, replacing the earlier frozen `numbers.js`). Everything stored uses ids, never numbers.
- `web/js/version.js` is overwritten by CI with the release number (`1.0.<run number>`) and commit, shown at the bottom of Settings. Keep the committed copy empty (it reads "development version" locally).
- Sound: CC0 Karoryfer "darkblack" bass samples in `web/audio/bass/` (B0–E4, plus ghost notes); `web/js/audio.js` falls back to a synth.
- Design: navy/teal/periwinkle/peach palette (no brown fretboard), real string-gauge proportions, root markers drawn as rounded squares. Keep this look.
- Downloading anything new (samples, packages, SDKs) needs the user's explicit OK first.
- Jazz licks (`curriculum/licks.js`) are ORIGINAL phrases in standard jazz vocabulary, notated in C (or C minor) and transposed. Never paste note-for-note transcriptions of copyrighted recorded solos.

### Decisions QA should not re-report
- The Course (user, 2026-10-20): a guided path of stages, units and lessons built on the existing exercises (each lesson: idea, concept, "Hear it" demo, practice steps, make music, common mistakes; a checkpoint per unit, a test per stage). A step passes on the goal tempo the app records for a full loop at the lesson's options plus the player's own ✓ Clean tick (no goal: one loop). Nothing is locked; the course recommends the next lesson. Home is course-first (Continue + a 15/30/45-minute session with spaced reviews after 1, 3, 7, 21 and 60 days); Path and Library stay. Lesson steps do not change the exercise's saved options, tempo, subdivision or best tempo; a step's backing does not change the Backing setting. Phase 1 covers Stages 1–2 (Levels 1–2); later stages follow.
- Course pass mark (QA round 8, user's choice): only a full loop counts (started on the first note, credited at the slowest tempo it was played at). A step sets its notes per beat (`sub`); a goal is "96 BPM in 8ths", and another subdivision shows "↺ Options" and does not count. ✓ Clean does not untick in the exercise (a ↺ on the lesson page does, after a question). Steps without a goal (ear rounds) ask "✓ Got them all?".
- Sessions (QA round 8, user's choice): the warm-up and the ear/reading drill come from lessons already done or known; a lesson not started opens with its demo; review items open in review mode (`rv=1`). Known (placement) lessons feed reviews too, and when nothing new is left the session adds Library Level 3 exercises until Stage 3 exists. Home says "known", not "complete", for placed-out units.
- Quiz mode (QA round 8, user's choice): in every exercise the tab strip shows "?" for notes not yet played; on the staff it shows no note names (the notes stay: reading is the skill).
- Instructions and explanations (lesson step texts, goal hints, the written-rhythm and backing explanations, the fret-limit notice) open as a note with a × that stays until closed or the screen changes; short confirmations still fade (user, 2026-10-20).
- Shape lines (QA round 8): grooves and chord-tone patterns that are a hand shape (R-5-8, octaves, R-5-♭7-8, boogie, shuffle, riffs, R-3-5-7…) keep each chord's notes around a fretted root (open strings only where no fret has the note, the low E), roots above fret 9 drop an octave, and disco octaves are two strings up, two frets up.
- Navy/teal/periwinkle/peach design; root notes drawn as rounded squares; real string-gauge proportions.
- The signing key `android/app/bassclass.p12` is committed on purpose (sideloaded app; updates must install over each other).
- Jazz licks are original vocabulary, not transcriptions.
- The tuner cannot open the microphone on plain `http://` pages (browser rule); it works on https, localhost and in the APK.
- Scale and pentatonic positions are numbered from the root (Position 1 = the box with the root on the E string); a position that would start above fret 12 is played an octave lower. (QA round 1, user's choice.)
- Inside a level the path lists hands and time first: technique, rhythm, fretboard, reading, intervals, ear training, scales, modes, triads, arpeggios, harmony, grooves, walking, licks, slap. (QA round 1, user's choice; reading and ear training added in round 4.)
- Notation (round 4, engraving redone in round 5 in the style of the user's Polyrhythm project, `views/staff.js`): bass guitar is written in the bass clef an octave above its sound (open E on the first ledger line below). Key signature and time signature are drawn. An accidental holds to the end of its bar (standard rule); a note that returns to the key signature in the same bar shows a natural. Written notes up to C5 use ledger lines; higher ones are drawn an octave lower under a dashed "8va". Real values: dotted notes, ties across beats and bar lines, rests per value, beams per beat (7/8 as 2+2+3, compound time in dotted quarters), triplets and other tuplets with their number. Swing is written as straight 8ths under "Swing" (written triplets stay triplets). Tuplets are named by how many fill a beat (3, 5, 6, 7); 12/8 is written in dotted-quarter beats. Ghost notes are × heads without accidentals (circled for half notes); harmonics are diamonds at their sounding pitch (open for half and whole notes). Dynamics go below the staff; implied chords in parentheses. Single-key scales, modes and harmonised chords write their key signature (modes the parent's; harmonic and melodic minor, minor pentatonic and blues the tonic's minor key); cycles, jazz lines and synthetic scales keep accidentals. (QA round 6, user's choice.)
- Backing (round 4): Off / Drone / Chords under ⋯, saved as a setting. It follows the badges, but only real harmony counts: a chord symbol (with slash bass) plays its chord up to the 7th, a note plus a scale or mode name plays that scale's triad. Words that start with a note letter ("Charleston", "E string") and badges without a note name ("#3", "Pos 2") play nothing. It is off for technique, rhythm, fretboard, intervals and ear training. (QA round 5.)
- Ear training (round 4): each round is heard with its notes hidden (no dots, "?" in the strip), then a silent answer step shows the name and the shape. The next-note preview never shows an answer. Answer shapes have one note per string.
- Reading drills show no note names: the staff is the only clue (Quiz mode, dots appear as the notes sound). Melodies avoid tritone leaps. (QA round 5.)
- Approach and enclosure notes are labelled "→" in every module. Licks label the other notes against the chord under them in jazz terms (9, ♭9, ♯9, 11, ♯11, ♭13, 13); a dominant's ♭9/♯9 always keeps its name.
- Lick notes are spelled against their chord. Chord tones keep their academic spelling; tensions, blue and passing notes with a double accidental become the plain enharmonic, and the ♯9 uses whichever of ♭3/♯2 reads more easily (B♭ over G7, B over A♭7).
- When an exercise physically cannot fit under "Highest fret used" (e.g. two octaves of E♭ on a 4-string with 17 frets) it goes over and shows a notice. Intended.
- Double accidentals are drawn as two glyphs (♭♭/♯♯), not 𝄫/𝄪, because Android system fonts may lack those characters.
- Exercises with a written rhythm (licks, grooves, walking, approach drills) hide the subdivision selector and show "♪ Written rhythm".
- Library shows every exercise by level (with search and level jump buttons); the Path shows the topics. The user asked for this swap (2026-10-15): do not suggest swapping the names back. Inside each level the Library uses the path's topic order, then the exercise number (QA round 3, user's choice), so new exercises sit with their topic.
- Spelling rule (user, 2026-10-15): the academic spelling, so no musician can call it wrong; where a widely used simpler spelling is also accepted, the simpler one. In practice:
  - Keys and chords chosen on their own get lead-sheet names: never B♯, E♯, C♭ or F♭; flats on black keys except minor-type chords/scales (C♯m, G♯m, F♯m); a minor key with a raised 6th/7th is named after its key signature (G♯ harmonic minor). Cycle drills use the cycle's names (C F B♭ E♭ A♭ D♭ G♭ B E A D G) unless that would force a double flat (F♯m, D♯°).
  - Notes keep their academic spelling: scales use each letter once (G♯ harmonic minor has F𝄪), chord tones keep their interval (the 3rd of D♯7 is F𝄪), and chords/modes inside a key keep the key's spelling (C♭ is the IV of G♭ major). Interval and chord-construction drills keep textbook spellings (B♭♭).
  - Only in jazz exercises (progressions, walking, grooves, licks, altered chord-scales): altered notes, diminished 7ths, blue and passing notes with a double accidental or C♭/F♭/E♯/B♯ are written the plain way (A♭7♭9: A; C°7: C E♭ G♭ A; ♭13 of E♭7: B). `Builder(ctx, S, { jazz: true })`. Chord tones stay academic there too: the ♭3 of a minor chord (A♭m7 = A♭ C♭ E♭ G♭), the ♭5 of m7♭5 and ° chords, the ♭7 of any non-major chord. A ♭3 over a major or dominant chord and a ♭7 over a major chord are blue notes (plain). On a dominant the ♭9/♯9/♯11/♭13 are alterations even when the symbol names them (A♭7♭9: A). Licks keep a natural ♯11 over a major chord (E♯ in a C♯ triad over B).
  - Plain-spelled scales name their keys with flats on the black keys (D♭ whole-half, A♭ Messiaen mode 7).
  - The altered scale over its dominant is written the jazz way everywhere it stands alone (Mode study, Pitch axis, chord-scale): G A♭ B♭ B D♭ E♭ F = R ♭9 ♯9 3 ♭5 ♭13 ♭7. Inside the melodic-minor family exercise it keeps the parent's spelling and labels (♭4, ♭6).
  - Scales without one note per letter (diminished, whole tone, augmented, Messiaen's modes) are spelled plainly: no double accidentals, no C♭/F♭/E♯/B♯ (`Builder(ctx, S, { plain: true })`). On them the "skip one note" sequence is called "Skip one note", not "In 3rds".
  - Parallel modes and pitch axis: each mode takes its most readable root name (C♯ Dorian, D♭ Lydian); when it differs from the chosen key the badge adds "(= D♭)". (QA round 3, user's choice.)
  - A scale or mode chosen on its own takes its plain name unless that name's key signature needs six or seven accidentals; then the enharmonic name with fewer (F♯ Mixolydian, not G♭ Mixolydian with seven flats; A♯ Locrian). Blues scales take their key's lead-sheet name and write the blue note plainly (E♭ blues: E♭ G♭ A♭ A B♭ D♭). Key chips follow the same rule (`tonicFor`). (QA round 7, user's choice.)
  - Progressions keep the key's spelling (G♭ C♭ D♭ G♭); a chord that would need a double accidental takes its lead-sheet name (C♭7 → B7), and so does any chromatic chord. (QA round 7.)
  - Pentatonic superimposition spells notes against the chord; when that changes the pentatonic's own letters (over an altered dominant) its name adds "(spelled from the chord)". (QA round 7.)
  - Licks name the tritone and the minor 6th as they are spelled (D♭ over G7 = ♭5, C♯ = ♯11); a note respelled plainly keeps its jazz name (B over E♭7 = ♭13). (QA round 3, user's choice.)
- A favourite stores the exercise only, not its options; it opens with the last options you used. (QA round 2, user's choice.)
- Over the V7(♭9) of a minor ii–V–i, the chord-scale exercise (and the walking lines) use Phrygian dominant (♭9, ♭13). (QA round 2, user's choice.)
- The UI uses British spelling ("favourites", "colours", "practise", "harmonised"); the Library search also finds the American spelling.
- Sound (user, 2026-10-15): no sound options in Settings. Always the recorded bass (the synth only while samples load), no octave-up layer, phone-speaker profile fixed at +15 dB. The bass volume is shown as 0–100% (internally 0–2 into the limiter; default 100%). The phone-speaker profile plays only in the Android app on the phone's own speaker (Android 13+: the device actually playing media); browsers always get the natural sound, because they cannot see headphones.
- Broken chords end on the root held to the bar line, so every key starts on beat 1. Two-octave arpeggios and scales always start on the E string ("Root on" shows as fixed). In one-octave scale and triad drills a root that would sit at frets 10–12 of the chosen string moves to the string below, shown as fixed (A major from the A string → E string fret 5); a root at fret 1 moves to the string below too (from the lowest string, to the one above: F from the E string → A string fret 8).
- Chord-scale (QA round 4, user's choice): modes by function, Berklee style. Diatonic chords take the mode of their degree (I Ionian, ii Dorian, iii Phrygian, IV Lydian, V Mixolydian, vi Aeolian, viiø Locrian; minor key: i Aeolian, iiø Locrian, iv Dorian, V7 → minor Phrygian dominant); other chords by quality (secondary dominant Mixolydian, m(maj7) melodic minor, °7 whole-half). Dominant tensions are named 9, 11, 13. A one-chord minor vamp is Dorian (QA round 6, user's choice). Chord-scale drills are written 8ths, so the subdivision never moves a chord off its bar line.
- Pop, rock, folk, disco and reggae progressions are triads (A E F♯m D); jazz, soul, funk and blues keep 7th chords. Exercises whose voicing needs a 7th (shells, R-7-10, R-3-5-7 patterns) use 7th chords on any progression. (QA round 4, user's choice.)
- Warm-ups at Levels 1–2 keep the range, position, zone and string options at their defaults, and pick only the first grades' keys (C G F D A E).
- The 3 scale fingerings (`tri-scale-forms`, id kept) is a Scales exercise (QA round 6, user's choice). Its finger-1 major form is the stretch form 1-3-4 | 1-3-4 | 2-3; the little finger may stretch one fret beyond the position instead of a shift.
- Ear training: 7th chords are voiced R-5-7-10 in one hand position (triads close).
- An exercise that is a preset of another keeps the option that gives it its name (e.g. Giant Steps arpeggios only offer Giant Steps; open spread triads have no Stack option).
- On scales without one note per letter the sequences are "Skip one note"/"Skip two notes"; the Barry Harris scale is harmonised every other note (C6 and dim7 chords).
- Settings sliders (bass and metronome volume) both run 0–100%.
- "World scales" (not "exotic"); the augmented scale is in it and in Symmetric scales. (QA round 3, user's choice.)
- Mode study offers every mode family (major, melodic minor, harmonic minor, harmonic major) even though it is Level 4 and the dedicated family exercises come at Levels 5–6: it is a free practice tool. (QA round 3, user's choice.)
- Slap (QA round 5): a hammer-on goes up and a pull-off goes down on the same string as the note before, and a run of them fits one four-fret hand position (otherwise the note is thumbed or popped). A pop never sits on the string the thumb just played (the octave pop goes two strings up). Pops sit on the top strings (D and G, also C on a 6-string); the thumb plays the low strings, an open string when one has the note, never the low B for a note the E string can take; a note too low to pop is thumbed. (QA round 7.)
- Pentatonic side-stepping: the outside bar is text and a parenthesised name in the strip, not a chord, so the Backing stays on the home key; every part is whole bars of written 8ths. (QA round 7.)
- Staff layout (QA round 7): tuplet numbers of stem-down groups sit above the note heads; dynamics have their own row above the labels; a chord's labels stack when they do not fit side by side; the staff never shrinks below size 6. A variation may suggest its own tempo (the 12/8 slow blues opens at 60).
- Walking lines (QA round 5): the octave of each root and whether each bar walks up or down from it (R 3 5 8 or R 7 5 3) are chosen for the whole line at once, so bars join by step or small leap and the loop closes near where it started. Passing 2nds and 6ths come from the chord's mode by function (same table as the chord-scale exercise). Two-feel plays half notes. Inside a long chord an approach leads back to its own root.
- Harmonised triads and 7ths (QA round 5): each chord is one hand shape (four frets at most) near the starting position; two notes on a string are fine, three never.
- Jazz spelling (QA round 5): the ♭9/♭13 of a non-dominant chord (Phrygian, Aeolian, Locrian) and the ♯11 of a major chord (Lydian) keep the key's spelling (C♭ in E♭m7 of G♭ major); on a dominant they stay plain alterations.
- Barry Harris dim7 → minor (#152): the diminished chord takes its jazz name (G°7 → G♯m, not F𝄪°7). (QA round 5, user's choice.)
- Exam-board references (QA round 5, user's choice): about texts say a topic "appears in" or "is typical of" graded exams; they never claim a specific grade requires it. The Source line keeps the references.
- String choices follow the bass (user, 2026-10-20): "Root on" lists every string with room for the shape above it (4-string E A D; 5-string adds the low B; 6-string adds B and G); shapes that need two strings above (octaves, md-study, moving intervals) add B on 5-string and B and D on 6-string; one-string drills offer every string (low B, high C). Options marked `{ minStrings }` only appear on those basses, and the self-test tries them only there.
- Soloing content from the Scott's Bass Lessons soloing playlist (user, 2026-10-20): concepts only, every line is original. Pentatonic superimposition plays the major pentatonics that lie wholly inside each chord's scale by function, ranked by chord tones (3rd and 7th first); over 7alt only the tritone pentatonic fits. Melodic-minor superimposition plays each chord's parent melodic minor from the parent's own root, named by its interval from the chord root (A♭ over G7alt) and spelled against the chord the jazz way. Chord types 7♯11, 7♭13, 7alt and 7sus♭9 exist for this.
- Licks: a progression entry can be implied (`[where, type, beats, { implied: true }]`): it shows as text ("implies G7♭9") with no chord badge, so the Backing keeps the vamp, while the labels follow the implied chord. One lick exercise may mix minor and major licks (`lick.minor`, `lick.keys`); its key chips follow the chosen lick (`minorWhen`).
- Every scale-based exercise has a Range option with 2 octaves (user, 2026-10-15). Exceptions, by nature: scales along one string (12 frets per octave), one position or box (all keys in one position, the 7 major and 5 pentatonic positions), scale in octaves (double stops on a string pair) and chord-scale progressions.
